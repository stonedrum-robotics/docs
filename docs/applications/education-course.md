# Learning exercises

The offline examples can be used to explore the distinction between an interface, an implementation and evidence of a physical result.

## Suggested exercises

1. Inspect `Hand.mock()` and compare target dictionaries with returned state.
2. Compare `move_to_grasp("open")` with `open()` and explain the different results.
3. Call `Finger.validate_positions()` explicitly and distinguish its range check from the general command path.
4. Supply a canned teleoperation frame and list the additional components a real input adapter would require.

These topics describe possible learning activities; they do not advertise a delivered university course, staffed workshop, hardware qualification or measured learning outcome. Keep exercises offline unless a separate physical-activity review establishes the configuration and responsibilities.

Start with [basic control](../tutorials/01-basic-control.md), then [grasp sequences](../tutorials/02-grasp-sequence.md).
