# Research experiments

The in-memory SDK can support small software exercises: inspect a target dictionary, compare returned joint objects, test handling of unknown names, or separate supplied commands from an input adapter. These are interface experiments, not measured manipulation performance.

## Designing an evaluation

State the task, chosen hardware/model, software revision, observation/action representation and success measure. Keep generated mock values separate from captured device data. A reproducible result needs the actual environment and evidence for the behavior being measured.

The current source does not establish tactile sensing, calibrated kinematics, object grasp success, synchronized RGB-D recording or a complete research platform. No hardware/arm/model performance or support service follows from these examples. See [training-data concepts](../concepts/training-data.md) and [simulation questions](../tutorials/05-sim-mujoco.md) for the relevant boundaries.
